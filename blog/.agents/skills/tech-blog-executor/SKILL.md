# Tech Blog Executor Specialist

이 스킬은 `tech-blog-analyzer`가 제공한 분석 리포트를 기반으로 실제 코드를 수정하고 결과를 검증하는 데 사용됩니다.

## 작업 원칙

1. **정확한 수정:** `replace` 도구를 사용하여 `tech-blog-analyzer`가 명시한 `old_string`을 정확히 찾아 수정합니다.
2. **코드 무결성 유지:** 중복된 스타일 정의나 닫히지 않은 태그 등 문법적 오류가 생기지 않도록 주의합니다.
3. **다크 테마 및 반응형 준수:** 색상은 항상 `:root` 변수를 사용하며, 미디어 쿼리의 무결성을 해치지 않습니다.

## 작업 워크플로우

1. **분석 리포트 확인:** `tech-blog-analyzer`로부터 전달받은 대상 파일과 수정 지침을 숙지합니다.
2. **사전 검토:** 수정 대상이 될 코드 블록(`old_string`)이 파일 내에 유일한지 확인합니다.
3. **작업 수행 (Execution):** `replace` 또는 `write_file`을 통해 코드를 수정합니다.
4. **검증 (Validation):**
   - 수정된 부분의 코드 문법을 확인합니다.
   - 레이아웃이 깨지지 않았는지, 의도한 디자인이 반영되었는지 최종 확인합니다.
