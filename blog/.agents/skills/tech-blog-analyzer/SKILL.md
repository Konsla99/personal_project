# Tech Blog Analyzer Specialist

이 스킬은 복잡한 테크 블로그 소스 코드에서 수정이 필요한 범위를 정확하게 특정하고, 수정 가이드를 생성하는 데 사용됩니다.

## 작업 원칙

1. **정밀 분석:** `grep_search`를 사용하여 수정 요청과 관련된 CSS 클래스, ID, HTML 태그의 모든 출현 위치를 확인합니다.
2. **구조적 맥락 파악:** 단순히 텍스트만 찾는 것이 아니라, 해당 코드가 어떤 컨테이너(`div`, `section`)에 속해 있는지, 다른 요소와 어떤 영향을 주고받는지 파악합니다.
3. **분석 리포트 생성:** `tech-blog-executor`가 바로 작업할 수 있도록 다음 정보를 포함하는 리포트를 작성합니다.
   - **대상 파일:** 수정할 파일 경로
   - **코드 블록:** 현재 코드의 고유한 `old_string` (충분한 컨텍스트 포함)
   - **수정 목표:** 변경해야 할 구체적인 속성 또는 내용
   - **주의 사항:** 미디어 쿼리(`@media`) 영향도, 변수 사용 여부 등

## 분석 워크플로우

1. **기초 조사:** `style.css`에서 레이아웃 관련 `:root` 변수와 공통 클래스를 먼저 확인합니다.
2. **범위 확정:** 요청받은 디자인 변경 사항이 영향을 미치는 HTML 섹션과 CSS 선택자를 특정합니다.
3. **중복 검증:** 동일한 스타일이 다른 페이지나 요소에도 적용되는지(`all-posts` vs `single-post`) 확인하여 부작용을 방지합니다.
4. **결과 전달:** 최종 분석 리포트를 작업 에이전트에게 전달합니다.
