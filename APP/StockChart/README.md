# 📈 StockChart - 주식 차트 분석 웹 애플리케이션

본 프로젝트는 주식 검색 기능을 기반으로 **피보나치 되돌림(Fibonacci Retracement)** 및 **빗각 채널(Trend/Pitchfork Channel)** 자동 그리기를 지원하는 반응형 웹 애플리케이션입니다. 추후 모바일 앱(하이브리드 앱) 버전으로의 확장을 염두에 두고 설계되었습니다.

---

## 🎯 프로젝트 목표
1. **신속하고 정확한 주식 검색**: 국내외 주식 데이터 검색 및 로드
2. **자동 차트 분석 (Auto-Drawing)**:
   - **피보나치 되돌림**: 특정 기간 내 최고점과 최저점을 탐색하여 `23.6%`, `38.2%`, `50.0%`, `61.8%`, `78.6%` 선을 자동으로 차트에 작도
   - **빗각 채널 (Parallel/Trend Channel)**: 주가의 고점들과 저점들을 연결하는 추세선을 분석하여 평행 채널을 자동으로 계산 및 시각화
3. **모바일 우선(Mobile-First) UI/UX**: 모바일 화면에서도 터치 제스처로 차트를 확대/축소 및 이동하기 편한 인터페이스 제공
4. **모던 & 프리미엄 디자인**: 다크 모드 기반의 네온 그래디언트와 미세 애니메이션을 적용한 프리미엄 비주얼 구현

## 📈 주요 수학적 구현 개념

### 1. 피보나치 되돌림 자동 작도
- **탐색 영역**: 사용자가 선택한 기간(예: 최근 50봉, 100봉) 내의 최고가($H$)와 최저가($L$)를 검출합니다.
- **되돌림 비율 계산**:
  $$R_p = L + (H - L) \times p \quad (p \in \{0.236, 0.382, 0.500, 0.618, 0.786\})$$
- **렌더링**: 차트 캔버스 위에 각각의 가격 수평선과 비율 텍스트를 오버레이로 그립니다.

### 2. 빗각 채널 자동 작도
- **추세선 탐색**: 특정 윈도우 내에서 고점(Swing Highs)들과 저점(Swing Lows)들을 알고리즘(예: 선형 회귀 또는 3점 탐색)을 통해 검출합니다.
- **채널 중심선 계산**: 고점과 저점의 중간 흐름을 따르는 중심 기울기를 구합니다.
- **상하단 채널선 작도**: 중심 기울기와 평행하면서 가장 바깥쪽 고점과 저점을 통과하는 평행선을 그립니다.

## 📱 모바일 대응 전략
- **터치 프렌들리 컨트롤**: 손가락 드래그를 통한 차트 이동, 핀치 투 줌(Pinch-to-zoom)을 통한 줌인/아웃 지원
- **반응형 레이아웃**: 데스크톱에서는 사이드바 형태의 검색창 및 지표 설정을 보여주고, 모바일에서는 하단 시트(Bottom Sheet) 또는 슬라이드 메뉴 형태로 최적화
- **성능 최적화**: 캔버스 드로잉의 스로틀링(Throttling)을 통해 모바일 기기에서의 발열 및 렉 방지
